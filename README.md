# QQ 群聊日报助手

一个开箱即用的工具：自动收集 QQ 群消息，用 DeepSeek 提炼「重要信息」和「待办事项」，只保留有用内容，可定时总结并推送到邮箱。全程网页操作，无需敲命令。

## 三步开始

### 1. 双击启动
双击 `start.bat`，浏览器会自动打开配置页面（http://127.0.0.1:8090）。
> 没自动打开就手动访问 http://127.0.0.1:8090

### 2. 页面填 DeepSeek Key
- 到 [platform.deepseek.com](https://platform.deepseek.com) 注册并创建 API Key
- 粘贴到「接入 DeepSeek」，点「测试连接」确认，再点「保存全部设置」
- 不填 Key 也能用，只是退化为本地关键词规则

### 3. 接入 QQ（需要 NapCat）
- 到 [napcat.napneko.icu](https://napcat.napneko.icu) 下载安装 NapCat，用 QQ **小号**登录
- NapCat「网络配置」新增一条 **HTTP 上报**，地址填页面提示的 `http://127.0.0.1:8090/onebot`
- 页面右上角状态变绿即成功

## 核心设计

- **只保留有用信息**：消息进来先进入临时缓冲，按你设置的频率提炼「重要信息 + 待办事项」后，源消息立即清空，不囤积原始数据。
- **定时频率可设**：从每 30 分钟到每天一次。
- **数据默认存 D 盘**：`D:/qq-digest-data`，可在页面修改（改后重启生效）。
- **邮箱推送（可选）**：提炼出新重点后自动发邮件；支持 QQ/163/126/Gmail/Outlook 一键预设，也可自定义 SMTP。

## 常见问题

**Q：为什么要用 NapCat？封号吗？**
QQ 官方不开放个人账号群消息接口，NapCat 是协议挂载方案，存在账号风控风险。务必先用小号验证。

**Q：程序要一直开着吗？**
要。需要本程序保持运行，且电脑开机、NapCat 保持登录。

**Q：数据存哪、安全吗？**
数据库默认在 D 盘 `D:/qq-digest-data`（含 `qq_messages.db`）。源消息在总结后即删除，只保留提炼结果。数据不上传任何服务器（用 DeepSeek 时会发送待总结的消息文本给 DeepSeek API）。

**Q：邮箱授权码是什么？**
QQ/163 等邮箱出于安全不再用登录密码发信，需在邮箱设置里开启 SMTP 并生成「授权码」，填入「授权码」一栏。

## 文件说明

| 文件 | 作用 |
|---|---|
| `server.js` | 后端（接收消息、提炼、邮件、网页） |
| `index.html` | 网页界面 |
| `config.json` | 配置（自动生成） |
| `start.bat` | 一键启动 |
